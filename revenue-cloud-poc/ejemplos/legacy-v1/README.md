# legacy-v1

Casos generados con la primera versión del formato, conservados **sin modificar** como referencia
histórica. No pasan el validador actual (`validate_manifest_poc.py --gate` falla): carecen de
`Fuentes consultadas`, de las tablas 3.1 y 3.2 y de hash de aprobación, y conservan marcadores
`<completar>`. Para un ejemplo que sí pasa, ver `assets/ejemplo-MANIFIESTO-POC-APROBADO.md`.
